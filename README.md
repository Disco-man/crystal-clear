# Crystal Clear

Mobile app prototype for monitoring data-center cooling and environmental impact: water use, energy, efficiency, CO₂, and forecasts. All metrics are **mock data**.

## Quick start

**Requirements:** Node.js 18+

```bash
npm install
npm start
```

When the dev server starts:

- Scan the QR code with **Expo Go** (phone on the same Wi‑Fi), or
- Press **w** to open in a browser, or
- Press **a** / **i** for Android / iOS emulator

## Usage

The app has five tabs:

| Tab | What it shows |
|-----|---------------|
| **Dashboard** | Summary (water, energy, efficiency, CO₂) and user eco footprint |
| **Water** | Cooling water consumption (hour/day/month) with live chart |
| **Energy** | Pump and heat-exchanger usage vs traditional systems |
| **Efficiency & CO₂** | Thermal efficiency (%) and carbon per AI request |
| **Forecast** | Predicted water/CO₂ trends and load-reduction tips |

Navigate with the bottom tab bar. No login or setup required.
